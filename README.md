# Mahanaim FC — Football Excellence For Greater Good

Mobile-first static website for Mahanaim Football Club (Abuja, Nigeria, est. 2018).

- No framework, no build step: semantic HTML + one CSS file + vanilla JS + JSON content in `/data`.
- Deploy anywhere (Railway via `Dockerfile`, Netlify, Vercel, cPanel).
- Docs: `/docs` (design, sitemap, content model, assumptions, deployment, handover, test results).
- Phase-2 backend schema: `/supabase/schema.sql`.
- Staff editing guide: `/admin/`.

Local preview: `python3 -m http.server` inside this folder.
