MFCMahanaim FCStaff guide

Staff: updating the site (no coding needed)

  1. Players: open /data/players.json in Notepad. Copy a block, change name/position/number. Set "status":"current". Only add a photo filename after signed consent. Then edit /players/index.html card to match (same order).
  2. Results/fixtures: add a row to /data/fixtures.json AND to the table in /fixtures/index.html. Never invent scores.
  3. News: copy /news/golden-eaglets-4-2/index.html to a new folder, rewrite title/date/body; add a card to /news/index.html and /data/news.json. Every image needs alt text.
  4. Photos: put approved images in /assets/images/, keep each under ~200KB (resize on your phone), reference by filename.
  5. Before publishing: check the approval list in docs/ASSUMPTIONS.md — anything marked REPORTED/PROPOSED/CONTENT REQUIRED needs a board sign-off first.

Phase 2 option: import the JSON files into Supabase using /supabase/schema.sql and replace mailto forms with authenticated writes. Until then there is no admin login — which means there is nothing for attackers to log into.
